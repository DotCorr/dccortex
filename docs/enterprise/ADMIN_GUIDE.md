# Enterprise Admin Guide

Purpose: administer tenants, access, security settings, and operational policies.

## 1. Admin Capabilities

- Configure identity provider integration.
- Manage roles and user access.
- Review audit logs and security events.
- Set data retention and compliance settings.

## 2. Identity Setup

1. Configure OIDC/SAML provider values.
2. Validate sign-in and sign-out flows.
3. Enforce MFA through provider policy.
4. Validate role mapping for least privilege.

## 3. Role Administration

- Assign minimum required roles.
- Remove stale elevated access.
- Review role assignment changes weekly.

## 4. Audit and Compliance Operations

- Export and archive audit logs.
- Validate log forwarding to SIEM.
- Track privileged operation history.

## 5. Security Operations

- Rotate secrets and keys on schedule.
- Trigger emergency rotation after incident.
- Review vulnerability reports for remediation plans.

## 6. Quarterly Governance Checklist

- [ ] Access review completed.
- [ ] Audit retention policy verified.
- [ ] Backup restore drill reviewed.
- [ ] Open compliance exceptions reviewed.
