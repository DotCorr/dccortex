# Enterprise Support and LTS Policy

Purpose: define support commitments for enterprise self-host customers.

## 1. Release Channels

- Current: latest feature and security updates.
- LTS: stability-focused line with backported critical fixes.

## 2. Support Scope

Includes:
- Install and upgrade assistance.
- Incident triage and mitigation guidance.
- Security patch advisory support.

Excludes:
- Custom feature development outside support agreements.
- Unsupported infrastructure baselines.

## 3. Severity and Response Targets

- Sev-1 (platform down/security breach): response within 1 hour.
- Sev-2 (major degradation): response within 4 hours.
- Sev-3 (limited impact): response within 1 business day.
- Sev-4 (general requests): response within 3 business days.

## 4. Patch Policy

- Critical security fixes: expedited out-of-band releases.
- High severity: next patch window or hotfix if exploitability is high.
- Medium/Low: normal release cadence.

## 5. Incident Communication

- Initial incident bulletin with scope and impact.
- Regular updates until mitigation.
- Final post-incident summary with corrective actions.
